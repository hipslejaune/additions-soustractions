# Le défi des additions et soustractions

Jeu en ligne (thème Pokémon) pour s'entraîner aux additions et soustractions : questions à trous, chrono, historique des temps, 50 Pokémon à collectionner (un toutes les 5 bonnes réponses).

- `index.html` : le jeu (une seule page)
- `images/fond.jpg` : fond d'écran
- `images/pokemon/` : les 80 Pokémon découpés (50 servent de récompenses)
- `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` : icônes de l'onglet

L'historique et la collection sont enregistrés dans le navigateur de l'appareil utilisé.
